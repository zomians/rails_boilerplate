## Project Overview

This is a **Rails boilerplate** project using Docker for containerized development. The project is designed to quickly bootstrap new Rails applications with a standardized setup.

**Key Technologies:**
- Ruby (version configurable in `.env.development`)
- Rails (version configurable in `.env.development`)
- PostgreSQL (version configurable in `.env.development`)
- Docker & Docker Compose
- Tailwind CSS
- Import maps

## Setup & Development

### 必要なツール

- Docker (20.10+)
- Docker Compose (2.0+)
- Git (2.30+)
- Make (optional)

### セットアップ手順

用途に応じて2つの初期化コマンドを用意しています。

#### 1. 通常のRails開発の場合

```bash
# 環境変数の確認・調整 (.env.development を編集可能)
make init
make up
```

**`make init` で追加される主な設定:**
- `mini_racer`, `pry-rails`, `rspec-rails`, `factory_bot_rails`, `faker` 等の定番gemの追加
- Rails 8 デフォルトの `rubocop-rails-omakase` 設定

#### 2. ECサイト開発 (Solidus) の場合

```bash
# 環境変数の確認・調整 (.env.development を編集可能)
make init-ec
make up
```

**`make init-ec` で行われる処理:**
- Solidus用に最適化された Rails new
- Solidus gemの追加・インストール、DBマイグレーション、サンプルデータのロード
- 管理画面: `http://localhost:3000/admin` (admin@example.com / test123)

## Common Commands

All commands should be run from the repository root.

### Development Workflow

```bash
# Start all containers
make up

# Access the app container shell
make bash

# View available make commands
make help
```

### Inside the Container

Once inside the container (`make bash`), you can run:

```bash
# Run Rails console
rails console

# Run database migrations
rails db:migrate

# Run database setup
rails db:setup

# Generate a new model/controller/etc
rails generate model User name:string email:string

# Start Rails server (if not running via bin/dev)
rails server
```

### Docker Commands

```bash
# View running containers
docker compose --env-file .env.development ps

# View logs
docker compose --env-file .env.development logs app

# Stop containers
docker compose --env-file .env.development down

# Rebuild containers
docker compose --env-file .env.development build --no-cache
```

## Architecture & Configuration

### Docker Setup

1. **app service** (`Dockerfile.app`): Ruby/Rails環境。`/app` にマウント。`bin/dev` で起動。
2. **db service**: PostgreSQL。`postgres_data` ボリュームで永続化。

### Environment Variables

- `.env.development`: 開発環境用（コミット済み）
- `.env.production`: 本番環境用テンプレート（コミット済み）

**設計方針:**
- `.env` ファイルは使用せず、`--env-file` で明示的に指定。
- 開発環境: `docker compose --env-file .env.development`
- 本番環境: `docker compose -f compose.production.yaml --env-file .env.production`

## Deployment (Production)

このプロジェクトは Docker Compose を使用した本番環境デプロイをサポートしています。

### VPSへのデプロイ手順

1. **初回セットアップ**:
   ```bash
   git clone ...
   vi .env.production # SECRET_KEY_BASE, POSTGRES_PASSWORD を設定
   ```
2. **起動**:
   ```bash
   make prod-build
   make prod-up
   make prod-db-setup
   ```

### 本番環境操作コマンド

| コマンド | 説明 |
|---------|------|
| `make prod-up` | 本番環境を起動 |
| `make prod-down` | 本番環境を停止 |
| `make prod-restart` | 本番環境を再起動 |
| `make prod-logs` | ログを表示 |
| `make prod-bash` | appコンテナに入る |

## Troubleshooting

### Container Issues

```bash
# クリーンアップ後に再起動
docker compose --env-file .env.development down -v
docker compose --env-file .env.development up -d

# Rebuild from scratch
docker compose --env-file .env.development build --no-cache
```

### Permission Issues (Host)

```bash
# Fix ownership
sudo chown -R $(id -u):$(id -g) .
```
